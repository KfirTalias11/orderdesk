# OrderDesk interface

An operations workspace with a quiet stationery-shop character: warm paper canvas, white working surfaces, ink-colored text and evergreen actions. The order ledger is the main working surface; a compact order-entry form stays alongside it on desktop and precedes it on mobile.

Use system UI typography for familiar native controls, tabular numerals for amounts, subtle horizontal rules and restrained status badges. Preserve readable labels and visible keyboard focus. Error states must distinguish unavailable data from a zero count. No external assets or fonts are loaded.
